# DXF 处理工具概览

DXF（Drawing Interchange Format）是工程制图与 CAD/CAM 数据交换的工业标准协议。在凸轮数控磨削中，上游 CAD 软件输出的 DXF 往往存在图元混杂（样条曲线 SPLINE、三维多段线、离散短线段）、起点相位不统一、旋转方向相反等格式问题，直接用于数控编程会导致插补异常。

**Cam Grinding** 提供了专门针对数控加工优化的“DXF 处理”工具集，涵盖**多文件几何对比**、**参数化离散化与重采样**、以及**高保真圆弧拟合压缩**。

## 2. DXF 几何处理工作流

```text
上游 CAD 图纸 (.dxf) (含复杂 Spline / 混杂线元)
       │
       ▼
[DXF 离散化与重采样] ──(提取规则离散点集)──> 是否需要圆弧拟合?
                                             ├── 是 ──> [DXF 拟合圆弧 (0.1μm)] ──> 生成 G02/G03 圆弧插补 DXF / NC
                                             └── 否 ──> 直接用于代码生成点位插补
                                                               │
                                                               ▼
                                             [DXF 文件对比 (验证几何保真度)]
```

## 3. 数控几何规范要求

为保证数控磨削加工万无一失，输入软件的 DXF 轮廓建议满足以下工业规范：

* **原点位置**：工件旋转中心必须精确位于坐标系绝对原点 $(0, 0)$；
* **拓扑闭合性**：轮廓必须严格首尾封闭，杜绝重叠微小线段或自相交折线；
* **图元类型**：推荐使用轻量多段线（`LWPOLYLINE`），避免使用未分解的高阶样条或嵌套块引用（BLOCK）。
