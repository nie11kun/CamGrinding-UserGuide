# 1.1 系统要求与安装启动

一句话说明：介绍凸轮磨削软件的运行硬件/系统环境要求、免安装绿色部署方法与动态预热启动流程。

![启动预热画面](resources/splash_screen.png)

---

## 运行环境要求

### 推荐硬件与系统配置

| 硬件项 | 最低配置 | 推荐配置 |
| :--- | :--- | :--- |
| **操作系统** | Windows 10 (64-bit) / macOS 12+ | Windows 11 (64-bit 专业版/企业版) |
| **处理器 (CPU)** | 双核 2.0 GHz 以上 | 4 核或更高（支持 AVX2 指令集，多核并行加速） |
| **内存 (RAM)** | 4 GB | 8 GB 或更高 |
| **显示器分辨率** | $1366 \times 768$ | $1920 \times 1080$ 或更高（软件完美支持 Windows 高 DPI 缩放） |
| **接口要求** | USB 2.0 / 3.0 接口（使用硬件加密狗时必需） | 标准 USB-A 接口或经认证的 Type-C 转接器 |

---

## 软件安装与解压部署

* **绿色免安装设计**：
  * 软件采用免安装封装，无需向 Windows 注册表写入深层配置。
  * 下载发布的压缩包（如 `CamGrinding_v1.29.0_Windows_x64.zip`）。
  * 解压至非系统根目录的英文字符路径（例如 `D:\WorkProgram\CamGrinding\`）。
* **路径规范建议**：
  * 建议软件所在路径与待处理的 CAD 文件路径均避免包含特殊字符或超长路径。
  * 运行主程序 `CamGrinding.exe` 即可进入启动引导。

---

## 软件启动与预热机制

启动 `CamGrinding.exe` 后，系统首先呈现暗黑质感启动画面，并通过平滑进度条执行 5 个核心阶段的自动化预热与环境自检：

1. **阶段 1：运行时基础环境就绪**
   * 初始化多进程调度服务，分配 CPU 核心计算资源。
2. **阶段 2：Numba JIT 高性能加速引擎预热**
   * 自动在后台编译并预热多段圆弧拟合、直线逼近与等距包络重构核心算法，确保主界面启动后点击计算零卡顿。
3. **阶段 3：加密狗与授权检测**
   * 后台静默扫描 USB 硬件加密狗（Sentinel SafeNet）。
   * 若插入有效加密狗，直接免登进入主工作界面；若未插狗，自动呈现登录窗口。
4. **阶段 4：配置文件与零件库加载**
   * 读取本地配置目录 `~/.camgrind/` 中的上次工作参数与工件库列表。
5. **阶段 5：平滑淡入主界面**
   * 启动画面自动淡出，调出主窗口。

> [!NOTE]
> **预热机制说明**
> 首次启动时若 CPU 占用稍有上升属正常现象，此过程由 Numba JIT 即时编译器正在将 Python 密集型几何算法编译为机器底层原生指令集。
