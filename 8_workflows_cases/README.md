## 2. 工程案例实施通用准则

在开展任何凸轮磨削加工前，建议遵循以下“四步核查法”：

1. **图纸与坐标原点核查**：确认输入的 CAD 轮廓中心精确位于坐标原点 $(0,0)$，回转旋转方向与机床头架一致；
2. **砂轮与最小曲率干涉核查**：运行“凸轮转升程”工具，确认工件全周最小内凹曲率半径 $\rho_{\min} > R_w$；
3. **圆弧拟合平滑性核查**：圆弧拟合公差建议取 $0.1\ \mu\text{m}$，生成代码后在数控仿真器中预览进给速度平稳性；
4. **测量仪相位对齐核查**：测量中心夹持定位基准必须与磨床头架定位销/键槽基准严格同相，避免测量坐标系整体旋转。
