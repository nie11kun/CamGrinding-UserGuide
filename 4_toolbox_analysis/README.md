# 凸轮分析体系概览

在凸轮机构的工程设计与磨削验证过程中，运动学（Kinematics）与几何曲率特性是决定机构运行平稳性、高速动力学响应以及砂轮磨削可行性的核心指标。

**Cam Grinding** 的“凸轮分析”工具箱提供了一套双向互逆的数学分析链条，涵盖**轮廓到升程的微分求解**、**升程到轮廓的积分合成**、**动力学速度积分**以及**解析数学方程反求**。

## 3. 核心运动学与几何判据

在进行凸轮分析时，必须重点关注以下三个工程物理量：

1. **瞬时速度跃变（刚性冲击判据）**：
   * 若位移 $s(\theta)$ 曲线存在一阶导数不连续，速度 $v(\theta)$ 将出现垂直台阶，此时加速度理论上趋于无穷大，机构将产生剧烈的**刚性冲击**，通常只允许在低速手动机械中出现。
2. **瞬时加速度跃变（柔性冲击判据）**：
   * 若加速度 $a(\theta)$ 存在跳跃不连续，其导数（加加速度 / Jerk）趋于无穷大，机构在高速运转时将引发强烈的振动和噪音（**柔性冲击**）。高品质精密凸轮要求加速度曲线连续光顺。
3. **凸轮工作面最小曲率半径 $\rho_{\min}$（砂轮干涉判据）**：
   * 在磨削具有内凹形状的凸轮时，凹轮廓处的理论曲率半径 $\rho_{\min}$ 必须**大于外圆砂轮的实际加工半径 $R_w$**（即 $\rho_{\min} > R_w$）。若砂轮半径过大，将产生严重“过切（Under-cutting）”导致工件报废。
