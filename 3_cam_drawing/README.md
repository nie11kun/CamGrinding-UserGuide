# 绘图参数建模模块总览

在凸轮工程设计与数控磨削加工中，初始输入的工程数据形态多种多样，涵盖离散坐标采样、运动学升程表、既有 CAD 轮廓以及共轭机构约束。

**Cam Grinding** 提供了功能完备的“绘图参数”建模工具集，支持从不同数据源快速重构高精度的凸轮 CAD/DXF 几何模型，并同步完成运动学升程与曲率质量分析。

---

## 1. 建模路径与适用场景

软件内置四条各具特色的建模路径，满足不同设计与反求场景：

| 建模路径 | 输入数据源 | 核心算法与处理过程 | 适用工程场景 |
| :--- | :--- | :--- | :--- |
| **[XY 点位文件](xy_points.md)** | `.txt` / `.dat` 离散坐标点列 | 多列索引提取、去噪对齐、极坐标升程计算、DXF 闭合多段线生成 | 三坐标机（CMM）扫描点、激光反求点云、通用理论坐标转换 |
| **[CAM 数据文件](cam_data_file.md)** | 包含 `B/G/A` 标记的文本或 `.xlsx` 表格 | 分段角度展开、运动规律插值、随动件（滚子/平面）包络展开 | 基于升程规律的新凸轮正向设计、发动机配气凸轮型线设计 |
| **[CAM 图形变换](cam_transform.md)** | 既有凸轮 `.dxf` 文件 | 极径方向同升程缩放、法线方向等距偏置、坐标旋转 | 滚子中心轨迹与凸轮工作轮廓互换、磨损补偿轮廓重构 |
| **[CAM 共轭计算](cam_conjugate.md)** | 凸轮 1 轮廓 + 双摆臂机构参数 | 相对运动学反转、摆臂刚体位姿解算、共轭包络线求解与离群点过滤 | 高速无间隙凸轮分割器、自动织机共轭打纬凸轮机构设计 |

## 3. 输出成果与标准格式

通过本模块生成的成果文件具备高度的标准化与兼容性：

* **CAD 轮廓（DXF）**：遵循 AutoCAD R12 / 2000 工业标准，曲线由高密度精确多段线（`LWPOLYLINE`）闭合构成，可直接用于后续数控代码生成或导入 SolidWorks、Creo、AutoCAD 等工程制图软件。
* **运动学分析图表（HTML）**：基于 Plotly 矢量引擎生成，可实时测量任意转角下的升程、速度、加速度与曲率半径变化。
* **P65 测量仪数据（TXT）**：自动输出克林伯格（Klingelnberg P65）专用的极坐标升程对齐文件（`*-distance-*.txt`），精确记录每 $0.5^\circ$ 转角对应的名义升程。
