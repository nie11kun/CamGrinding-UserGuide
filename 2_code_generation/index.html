2. 数控加工代码生成

2.1 代码生成流程概览

一句话说明：基于砂轮几何包络理论与偏置中心轨迹算法，将二维凸轮闭合轮廓转换为数控磨床 X-C 轴联动磨削加工程序。

凸轮磨削加工原理与包络算法

凸轮磨削与普通车铣零件不同，其轮廓加工是由高速旋转的砂轮外圆与工件之间进行连续相切包络形成的：

  • 非圆轮廓联动：
    • 工件安装在回转工作台（C 轴），绕其回转中心旋转。
    • 砂轮沿径向（X 轴）进给，两轴紧密同步联动。
  • 砂轮中心运动轨迹（Tool Center Path）：
    • 随着砂轮磨损，砂轮外圆直径不断减小。
    • 相同的工件理论轮廓，对于不同直径的砂轮，其砂轮中心接触点法线偏置距离不同，对应的 X-C 轴联动轨迹完全不同。
  • 软件核心计算流水线：
    1. 读入原始凸轮 DXF，按照高精度进行等弧长高密离散采样。
    2. 针对指定范围内的每一级砂轮直径，计算各轮廓点处的单位法向量。
    3. 沿法线向外偏置 12×砂轮直径\frac{1}{2} \times \text{砂轮直径}21​×砂轮直径，求解砂轮中心坐标。
    4. 转换为极坐标直角分量或极角-极径关系，生成多直径跳表宏程序。
    5. 可选启用圆弧拟合，通过最小二乘逼近将高密离散点压缩平滑为多段连续相切圆弧。

代码生成模式对比：COMPCAD vs TRANSMIT

特性对比 离散点插补模式 (拟合圆弧 = 否) 圆弧拟合插补模式 (拟合圆弧 = 是)
插补指令 COMPCAD + G01 X=... C=DC(...) TRANSMIT + G02/G03 X=... Y=... CR=...
编程坐标系 工件回转极坐标系（X 轴直线进给 + C 轴角度旋转） 虚拟直角坐标系（通过 TRANSMIT 虚拟出 X-Y 平面）
程序段数量 通常为 3600 个微小直线段点 通常大幅压缩为数十段光滑相切圆弧
加工表面质量 取决于系统前瞻缓冲与压缩性能 极其平滑，无微小多边形接刀棱纹，粗糙度显著更佳
数控系统要求 西门子 840D / 828D 标准配置 需要开通西门子 TRANSMIT 柱面转换 选件授权
适用机床 所有具备 X/C 轴联动的数控机床 具备西门子 TRANSMIT 坐标转换的高精度数控磨床
